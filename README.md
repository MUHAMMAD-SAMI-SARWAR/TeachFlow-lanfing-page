# TechFlow Landing Page

A modern and responsive landing page built with Tailwind CSS v4 and vanilla JavaScript.

## 🚀 Features
- **Dark Mode:** Easily toggle between light and dark themes.
- **Responsive Design:** Optimized for all screen sizes (Mobile, Tablet, and Desktop).
- **Scroll Effects:** Navigation bar features a backdrop-blur effect on scroll.
- **Animations:** Smooth entrance animations for the hero section.

## 🛠 Tech Stack
- HTML5
- Tailwind CSS v4
- JavaScript (Vanilla)
- FontAwesome (Icons)

## 💻 Installation & Usage

1. **Clone the repository:**
```bash
   git clone [https://github.com/YOUR_USERNAME/techflow-landing-page.git](https://github.com/YOUR_USERNAME/techflow-landing-page.git)
Install Dependencies:
Navigate to the project folder in your terminal and run:

Bash
   npm install
Run Tailwind CSS (Development):
To compile and watch your CSS changes, run the following command:

Bash
   npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
Tip: You can add this to your package.json scripts under "dev": "npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch" to run it simply using npm run dev.
